# Клуб четырёх коней

Адаптивный лендинг по макету Figma: HTML, CSS и чистый JavaScript без библиотек.

## Демонстрация

- [chess-club.ux2.ru](https://chess-club.ux2.ru) — версия по ТЗ: только обязательная функциональность, без дополнительных анимаций
- [chess-club2.ux2.ru](https://chess-club2.ux2.ru) — версия с анимированными иллюстрациями

## Ветки

- `feat/layout` — основная вёрстка по ТЗ; соответствует [chess-club.ux2.ru](https://chess-club.ux2.ru)
- `feat/animations` — ответвление от `feat/layout` с дополнительными анимациями иллюстраций; соответствует [chess-club2.ux2.ru](https://chess-club2.ux2.ru)

## Замечания

1.В отдельных местах округлил значения из макета (например, 59px → 60px) и выровнял элементы по сетке там, где в Figma были расхождения на 1–2px. Сделано для единообразия и удобства поддержки.

2.На части экранов возможны небольшие смещения абсолютно позиционированных элементов из‑за различий в расчёте скроллбара между браузерами. Основные сценарии проверены в Chrome, Firefox, Safari.

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
npx --yes serve .
# или
python3 -m http.server 8080
```

## Структура

- `index.html` — разметка страницы
- `css/` — стили (reset, переменные, компоненты, секции)
- `js/` — бегущая строка, карусели этапов и участников, анимация появления
- `assets/images/` — изображения и иконки
- `docs/reference/` — PNG-референсы макета

## Функциональность

- Бегущая строка (CSS-анимация, бесшовный цикл)
- Якоря в hero: «Поддержать шахматную мысль» → `#lecture`, «Подробнее о турнире» → `#stages`
- Этапы: сетка на desktop, карусель без зацикливания на mobile
- Участники: карусель с зацикливанием и автопрокруткой каждые 4 секунды
- Плавное появление секций при скролле

## Брейкпоинты

- Mobile: от 375px
- Hero city (tablet): от 470px
- Desktop (сетка этапов, 3 карточки участников): от 1024px
- Session (двухколоночный layout): от 1120px
- Максимальная ширина контента: 1366px
